# Лабораторная работа №6. Unit-тестирование
Вариант 14, модуль «Автостоянка».

## 1. Классы, которые тестируем
Тестируются классы с логикой, не связанные с окном и базой:

| Класс | Метод | Что делает |
|---|---|---|
| `Check` | `Plate`, `Discount`, `Required` | проверяет госномер, скидку и обязательные поля |
| `Tariff` | `Calc` | считает стоимость стоянки с учётом скидки |
| `Debt` | `Of`, `CheckPayment` | считает долг и проверяет сумму оплаты |

Тесты лежат в `tests/Parking.Tests`: `CheckTests.cs`, `TariffTests.cs`, `DebtTests.cs`.
Каждый тест: создать данные, вызвать метод, сравнить результат с ожидаемым.
Класс тестов называется как проверяемый класс с приставкой Tests.

## 2. Таблица тестов

| Требование | Тест | Ожидание | Комментарий |
|---|---|---|---|
| Госномер 6–9 букв или цифр | `А123ВС77` | принимается | обычный номер |
| | 6 и 9 символов | принимается | границы |
| | 5 и 10 символов | ошибка | сразу за границами |
| | `A123-BC` | ошибка | спецсимвол |
| | пусто или пробелы | ошибка | обязательное поле |
| | `а123вс77` | `А123ВС77` | приводится к верхнему регистру |
| Скидка от 0 до 100 | 0, 15, 100 | принимается | границы и середина |
| | -1, 101 | ошибка | сразу за границами |
| | `abc`, пусто, `5.5` | ошибка | не целое число |
| Первые 15 минут бесплатно | 0, 10, 15 минут | 0 руб. | граница 15 |
| Каждый начатый час 50 руб. | 16 минут | 50 руб. | первый платный час |
| | 60 минут | 50 руб. | ровно час |
| | 61 минута | 100 руб. | начался второй час |
| | 180 минут | 150 руб. | три часа |
| | сутки / сутки и минута | 1200 / 1250 руб. | длинная стоянка |
| Скидка вычитается из цены | 2 часа, 10% | 90 руб. | |
| | 1 час, 50% | 25 руб. | |
| | 2 часа, 100% | 0 руб. | |
| Выезд не раньше въезда | выезд на 5 минут раньше | ошибка | |
| Долг = стоимость - оплачено | 100 и 30 | 70 | |
| | 100 и 100 | 0 | всё оплачено |
| Оплата от 0 (не включая) до размера долга | 50, 100, `25,5` при долге 100 | принимается | запятая тоже |
| | 0, -5, 150, `abc`, пусто | ошибка | |

## 3. Программа, выполняющая тесты
`tests/Parking.Tests/Program.cs`. Запуск:
```
dotnet run --project tests/Parking.Tests
```
Точка `.` — тест прошёл, `E` — тест упал.
