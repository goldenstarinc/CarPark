# Лабораторная работа №3. Выбор платформы и декомпозиция работ
Вариант 14. Модуль «Автостоянка».

## 1. Технологии
| Что | Выбор |
|---|---|
| Язык | C# |
| Платформа | .NET 8 |
| Интерфейс | Windows Forms |
| База данных | SQLite (один файл parking.db) |
| Доступ к БД | Microsoft.Data.Sqlite |
| Тесты | свой простой консольный запуск тестов |
| Версии кода | Git |

## 2. Почему так
- **C# и Windows Forms** — окно с таблицами и кнопками собирается быстро, не нужна вёрстка.
- **SQLite** — не нужен сервер, база лежит в одном файле рядом с программой.
- **Microsoft.Data.Sqlite** — официальная библиотека, обычный SQL без лишних надстроек.
- **Git** — хранит историю и позволяет вести работу ветками.

## 3. Декомпозиция (модули)
| Модуль | Файлы | За что отвечает |
|---|---|---|
| База данных | Db.cs, Db.Parking.cs, Db.Debts.cs | создание таблиц и все SQL-запросы |
| Правила | Check.cs, Tariff.cs, Debt.cs | проверка ввода, расчёт стоимости, долги |
| Интерфейс | MainForm*.cs, Program.cs | окно и вкладки |
| Тесты | tests/Parking.Tests | проверка правил |

Правило: расчёты не знают про окно и базу, поэтому их легко тестировать.
