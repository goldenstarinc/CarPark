# Лабораторная работа №5. Функциональное тестирование («чёрный ящик»)
Программа: «Автостоянка». Тестируем только через окно программы, код не смотрим.

## 1. Классы эквивалентности

| Поле | Допустимые | Недопустимые | Значения для теста |
|---|---|---|---|
| Скидка, % | целое от 0 до 100 | меньше 0; больше 100; не число; пусто | 50, 0, 100 / -1 / 101 / abc / (пусто) |
| Госномер | 6–9 букв или цифр | меньше 6; больше 9; спецсимвол; пусто | А123ВС77 / A1234 / A123456789 / A123-BC / (пусто) |
| ФИО, Марка | любой непустой текст | пусто | Иванов Иван / (пусто) |
| Сумма оплаты | число больше 0 и не больше долга | 0; отрицательное; больше долга; не число; пусто | 30 / 0 / -5 / 1000 / abc / (пусто) |
| Время выезда | не раньше времени въезда | раньше времени въезда | +2 часа / -1 час |
