# Техническое задание: «Автостоянка» (вариант 14)

## 1. Введение
Программа нужна сотруднику автостоянки, чтобы вести учёт машин, их владельцев, времени стоянки, оплаты и долгов.

## 2. Наименование и область применения
«Автостоянка». Используется на рабочем месте администратора стоянки.

## 3. Основание для разработки
Учебное задание по дисциплине «Технология разработки ПО», вариант 14.

## 4. Назначение
Хранить сведения о марке автомобиля, владельце, дате и времени въезда, стоимости стоянки, скидках и задолженности по оплате.

## 5. Технические требования
**Функции:**
1. Справочник владельцев (ФИО, телефон, скидка в %): добавить, изменить, удалить.
2. Справочник машин (госномер, марка, владелец): добавить, изменить, удалить.
3. Въезд и выезд машины с фиксацией даты и времени.
4. Расчёт стоимости: 50 руб. за каждый начатый час, первые 15 минут бесплатно, скидка владельца вычитается.
5. Учёт задолженности и приём оплаты.
6. История всех стоянок.

**Надёжность:** проверка вводимых данных, понятные сообщения об ошибках, целостность связей в БД.

**Среда:** Windows 10/11, .NET 8, БД SQLite (файл parking.db).

## 6. Стадии и этапы
Каскадная модель: требования -> проектирование -> реализация -> тестирование -> приёмка.

## 7. Порядок приёмки
Выполнение всех тестов из docs/lab5.md и docs/lab6.md.
